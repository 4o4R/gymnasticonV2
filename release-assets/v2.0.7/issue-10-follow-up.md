Follow-up: [v2.0.7 is now available](https://github.com/4o4R/gymnasticonV2/releases/tag/v2.0.7).

This release fixes clean shutdown on Raspberry Pi by releasing the native noble/bleno HCI handles, adds `--ant-enabled` / `--no-ant-enabled`, and unifies the systemd service used by image and manual installs. Both the modern Pi Zero 2 W image and legacy Pi Zero image are attached with SHA256 checksums.
